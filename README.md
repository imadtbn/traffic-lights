# مدرسة السياقة

منصة تعليم قيادة عربية ثابتة مبنية بـ **HTML وCSS وJavaScript Modules**. تجمع بين مكتبة إشارات المرور المصورة، قواعد القيادة، نصائح الأمان، المقالات القصيرة، واختبارات تفاعلية أساسية ومتقدمة مع حفظ النتائج محلياً.

## المزايا الرئيسية

| المجال | ما تم تنفيذه |
| --- | --- |
| الهوية والملاحة | هيدر احترافي ثابت، قائمة متجاوبة للهاتف، هوية لونية، أيقونة SVG، وفوتر مقسّم إلى ثلاثة أقسام. |
| الصفحات | الرئيسية، إشارات المرور، قواعد القيادة، نصائح الأمان، المقالات، مركز التقييم، اختبار الرخصة المتقدم، وصفحة النتيجة. |
| الاختبارات | اختبار أساسي من 10 أسئلة يغطي الإشارات العشر، واختبار متقدم من 12 سؤالاً في المواقف والطقس والمسافة والقرارات. |
| تتبع النتيجة | النتيجة والنسبة والتاريخ وأفضل نتيجة محفوظة في `localStorage` وتظهر في سجل التقدم. |
| المحتوى | أربعة مقالات عملية عن السرعة، مسافة الأمان، الاستعداد قبل الرحلة، والقيادة ليلاً. |
| SEO والفهرسة | عنوان ووصف وكلمات مفتاحية، Open Graph، Twitter Card، canonical، بيانات منظمة JSON-LD، `robots.txt`، `sitemap.xml`، وmanifest. |

## بنية الملفات

- `index.html`: القالب الدلالي والوسوم الوصفية وبيانات SEO المنظمة.
- `styles.css`: نظام التصميم المتجاوب للهيدر والفوتر والصفحات والاختبارات.
- `app.js`: التوجيه عبر hash routes، العرض الديناميكي، التصفية، المقالات، الاختبارات والتتبع.
- `data/content.js`: بيانات الإشارات وبنك الأسئلة الأساسي والمتقدم والمقالات.
- `assets/images/`: صور فوتوغرافية حقيقية لإشارات المرور.
- `assets/favicon.svg`: أيقونة الموقع بصيغة SVG.
- `manifest.webmanifest`, `robots.txt`, `sitemap.xml`: ملفات التعريف والفهرسة.

## التشغيل المحلي

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الاختبارات

يبدأ الاختبار الأساسي من `#tests`، بينما يبدأ اختبار رخصة السياقة المتقدم من `#advanced`. بعد اختيار إجابة يظهر تفسيرها، وفي نهاية الاختبار تُحفظ النتيجة محلياً وتظهر في «سجل التقدم». لا تُرسل النتائج إلى أي خادم.

## ملاحظة حول الفهرسة

الموقع يستخدم تنقلاً خفيفاً عبر hash routes حتى يعمل على الاستضافة الثابتة دون خادم. كما يتم تحديث عنوان ووصف الصفحة ديناميكياً عند تغيير القسم، وتوجد خريطة موقع وبيانات منظمة للصفحات الأساسية. عند تفعيل GitHub Pages، يجب التأكد من أن عنوان النشر يطابق الرابط الأساسي الموجود في `canonical` و`robots.txt` و`sitemap.xml`.
